# Changelog

## 1.0.0 (2026-11-19)

- Six Web Components: `<satelit-rates>`, `<satelit-converter>`, `<satelit-fuel>`, `<satelit-cinema>`, `<satelit-news>`, `<satelit-prices>`. Ro/ru/en, light/dark/auto, Shadow DOM.
- One bundle, `dist/satelit-widgets.js`, no dependencies.
- Key-holding proxies with an allow-list, per-route cache and CORS: Node (zero dependencies), Cloudflare Worker, single-file PHP.
- Demo page, offline tests with a mock API, live smoke test.
